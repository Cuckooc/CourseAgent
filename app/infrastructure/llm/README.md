# Model_LLM LLM 网关

LLM 网关层封装所有大模型调用：抽象基类定义提示词模板约定，网关负责主模型与降级模型的重试切换，业务类按场景组装提示词。

## 📁 目录结构

```
model_llm/
├── gateway.py       # ⭐ LLM 网关（主模型 + 降级模型重试链）
├── llm.py           # LLM 抽象基类（配置读取 + 网关客户端构造）
└── llm_business.py  # 业务提示词类（如内置知识库问答）
```

## 📄 文件详细说明

### `gateway.py` - 网关

**核心机制**:
- 主模型调用失败时按顺序重试降级模型（重试耗尽或致命错误才最终失败）
- 区分致命错误（401/403/非法密钥）与可重试错误（限流/超时），致命错误立即短路
- 统一记录 LLM 用量（对接 `core/usage.py` → Prometheus 指标）

### `llm.py` - 抽象基类

封装模型配置读取与网关客户端构造，**子类只负责提供提示词模板**。新增 LLM 业务场景 = 继承本类 + 定义模板，无需关心重试/降级/用量统计。

### `llm_business.py` - 业务提示词

内置基础知识库问答提示词类（仅依据 RAG 知识库作答，约束模型不编造知识库外内容）。

## 🔗 依赖关系

- 被 `multi_agent/` 全部 Agent、`service/`（preference 提取等）、`util/title.py`（标题生成）依赖
- 底层通过 dashscope SDK 调用通义系列模型（模型名与 Key 见 [env/README.md](../env/README.md)）
