# 用户使用说明

本说明面向 PBL 智能课程咨询服务（CourseAgent）的使用者，介绍账号注册登录及各功能模块的使用方法。

## 1. 角色说明

系统包含三类角色，登录后按角色展示对应功能：

| 角色 | 可使用功能 |
|---|---|
| 普通用户（user） | 对话咨询、历史信息、私有知识库、文档审核（本人）、个人信息 |
| 教师（teacher） | 普通用户全部功能，另可管理公共知识库、查看全部文档审核队列 |
| 管理员（admin） | 用户管理、用量统计、知识库查看、全量文档审核 |

## 2. 注册与登录

打开系统地址进入登录页，支持三种方式：

1. **账号登录**：输入用户名（或邮箱）与密码登录。
2. **邮箱验证码登录**：输入邮箱，点击「发送验证码」，查收邮件后填入 6 位验证码登录。
3. **注册新账号**：设置用户名、邮箱与密码完成注册，注册后即可登录。

> 登录令牌在浏览器标签关闭后失效，重新打开需再次登录。连续多次输错密码将临时锁定账号，请稍后再试。

## 3. 对话咨询

对话咨询是系统的核心功能，提供基于知识库的智能问答。

- **新建会话**：点击左侧「新建会话」开始一段新对话。
- **提问**：在底部输入框输入问题，按 Enter 发送；Shift + Enter 换行。
- **流式回答**：回答会逐字输出；灰色状态提示表示系统正在进行意图分析、资料检索或文档解析。
- **停止生成**：回答过程中可点击「停止」按钮中断，已生成的内容会保留。
- **附带资料提问**：点击上传按钮，可在当前会话中上传文档（会话级临时知识库），系统将结合文档内容作答。
- **回答反馈**：可对回答进行点赞/点踩，帮助优化回答质量。
- **切换会话**：在左侧列表点击任一会话即可查看和继续该对话。

提问建议：问题描述尽量完整，如问题涉及特定资料，请先上传对应文档再提问。

## 4. 历史信息

历史信息页集中管理全部会话：

- 按时间浏览会话列表与标题。
- 点击会话查看完整对话记录。
- 支持对会话重命名，便于归类查找。
- 删除会话需两步操作：先「预览」确认影响范围，再「确认」删除；误删后可在有效期内「撤销删除」。

## 5. 知识库

知识库用于管理可被问答引用的文档资料。

### 5.1 上传文档

- 支持格式：`.pdf`、`.txt`、`.md`；单个文件不超过 50 MB。
- 支持单文件或整个文件夹批量上传。
- 上传后系统自动完成解析、分块与向量化，扫描件 PDF 会自动进行 OCR 识别，处理时间相对较长。
- 上传范围：
  - **私有库**：仅本人可检索使用（默认）。
  - **公共库**：全体用户可检索，仅教师/管理员可上传。
  - **会话临时库**：仅在当前会话中生效。
- 同名或内容高度相似的文档会按去重与版本策略处理，避免重复入库。

### 5.2 管理文档

- 查看文档列表：文件名、分块数量、字符数、状态。
- 预览：在抽屉中分页查看文档分块内容。
- 删除：二次确认后，文档文件与向量数据一并删除。

## 6. 文档审核

文档上传后进入审核流程，保障知识库内容合规。

- **我的审核**：查看本人上传文档的审核记录与状态（待审核 / 已通过 / 已驳回）。
- **全部审核**：教师/管理员可查看全量待审队列。
- 审核操作：查看文档内容后执行「通过」或「驳回」，驳回后该文档不进入可检索知识库。

## 7. 个人信息

在「个人信息」页查看和维护个人资料（如专业方向、学习偏好等）。完善资料后，系统在对话中可提供更贴合需求的回答。

## 8. 管理员功能

### 8.1 用户管理

- 查看全部用户列表与角色。
- 调整用户角色（普通用户 / 教师 / 管理员）。
- 注销账户：先「预览」将被清理的数据范围，再「确认」执行；注销有宽限期，到期后数据彻底删除。

### 8.2 用量统计

按模型、按用户查看 LLM 调用次数与 Token 用量（请求数、输入 Token、输出 Token），支持手动刷新。

## 9. 常见问题

| 问题 | 处理方式 |
|---|---|
| 登录后提示未登录/跳转登录页 | 登录已过期，请重新登录 |
| 收不到邮箱验证码 | 检查垃圾邮件文件夹；确认邮箱填写正确；稍后重新发送 |
| 上传提示文件过大 | 单文件上限 50 MB，请压缩或拆分后上传 |
| 上传提示格式不支持 | 仅支持 PDF、TXT、MD 格式 |
| 扫描件处理很慢 | OCR 识别需要时间，请耐心等待状态更新 |
| 提示"操作过于频繁" | 触发了访问频率限制，请稍后再试 |
| 提示用量/额度受限 | Token 预算已达上限，请联系管理员调整 |

## 10. 隐私说明

- 密码经加密存储，任何人无法查看明文。
- 对话记录、上传文档与个人资料仅本人及有权限的审核人员可见。
- 删除会话或注销账户后，相关数据会按策略清理，不做其他用途。
