`app/application/ports` 访问基础设施，组合根 `app/api/deps.py` 是唯一允许
import infrastructure 的模块，在应用启动时完成 Port ↔ Adapter 装配。

## 2. 对话主流程走向（SSE 流式问答）

入口 `POST /chat/stream`：上下文增强 → 状态机编排 Agent 流水线 →
逐帧推回前端，异步沉淀历史与记忆。

关键容错：Analysis 为关键节点（诊断 + 重试）；RAG / File 为非关键节点，
失败仅降级为空结果；Verifier 校验不达标时走 Fallback 兜底。

```mermaid
flowchart TD
    A(["用户提问 ChatPage"]) --> B["POST /chat/stream（SSE 长连接）<br/>chat 路由"]
    B --> C["ChatService.handle_stream<br/>上下文增强：近期历史 + 早期摘要<br/>+ 用户画像前缀 + 会话关键词"]
    C --> D["AgentService.run_agent_stream<br/>PipelineStateMachine + MessageBus 编排"]

    D --> E{"VagueAgent<br/>是否闲聊？"}
    E -->|"是"| CHAT0["ChatAgent 直接作答"]
    E -->|"否"| F["AnalysisAgent 意图决策<br/>输出 need_RAGAgent / need_FileAgent<br/>（关键节点：诊断 + 重试）"]

    F --> G{"需要检索？"}
    G -->|"need_RAGAgent"| H["RAGAgent<br/>公共 + 本人私有持久库<br/>向量/关键词 RRF + rerank"]
    G -->|"need_FileAgent"| I["FileAgent<br/>当前会话临时库 + 本地 PDF 演示库"]
    G -->|"都不需要"| K
    H -.->|"非关键节点失败→空结果降级"| K
    I -.->|"非关键节点失败→空结果降级"| K

    H --> K["SummaryAgent 汇总双路结果"]
    I --> K
    K --> L{"Verifier 相关性校验<br/>达到阈值？"}
    L -->|"否"| FB["Fallback 兜底答案<br/>failure_diagnoser 记录"]
    L -->|"是"| M["ChatAgent 结合记忆生成最终答案"]
    CHAT0 --> N
    FB --> N
    M --> N(["SSE 逐帧推送前端"])

    N --> O["异步沉淀：问答落 history 表<br/>更新会话关键词 / 用户画像"]
    O --> P{"会话超长？"}
    P -->|"是"| Q["session_rollover 滚换：压缩摘要 → 长期记忆"]
    P -->|"否"| R(["结束，等待下一轮"])
    Q --> R

    classDef focal fill:#E5FFF2,stroke:#0FDC78,stroke-width:2px,color:#004D26;
    class H,I,F focal;
```

## 3. 文件入库流程（上传 → 解析 → 去重 → 向量入库）

对应代码：`app/api/v1/files.py`（路由/线程池）、
`app/application/files/file_service.py`（解析、脱敏、去重、入库）。
去重临界区 `_dedup_commit_lock` 按 `(scope, 归属, content_hash)` 串行化
「判定 + 提交」，叠加进程锁与 Redis 跨副本锁，防 TOCTOU 重复插入。

```mermaid
flowchart TD
    A(["前端 POST /files/upload<br/>表单：file + scope + dedup_strategy + update_strategy"]) --> B{"scope 校验"}
    B -->|"非法值"| B1(["400 BizException"])
    B -->|"public"| B2{"teacher/admin 角色？"}
    B2 -->|"否"| B2x(["403 拒绝"])
    B -->|"temp"| B3{"带 session_id？"}
    B3 -->|"否"| B3x(["400 拒绝"])
    B -->|"private"| C
    B2 -->|"是"| C
    B3 -->|"是"| C

    C["文件落盘 uploads/<scope>/<uid>/...<br/>生成 stored_name"] --> D{"批量大小"}
    D -->|"小批量"| E["同步：上传线程池 ThreadPoolExecutor<br/>每文件一个 worker"]
    D -->|"大批量"| F["异步：_async_upload<br/>返回 task_id，前端轮询进度"]
    E --> G
    F --> G["_process_saved_file<br/>FileService(path)"]

    G --> H{"scope？"}
    H -->|"temp（会话临时库）"| T1["process_temp_file<br/>提取 → 脱敏 → 父子块<br/>直接写会话临时 Chroma<br/>不去重、不临界区"]
    T1 --> T2(["结果 success/fail<br/>会话结束 drop，滚换 relocate"])
    H -->|"private / public（持久库）"| P0["process_file"]

    P0 --> P1{"文件类型路由 _extract_text"}
    P1 -->|".txt / .md"| X1["直接读取纯文本"]
    P1 -->|".pdf"| P2{"detect_pdf_type 分类"}
    P2 -->|"pure_text"| X2["PyPDF2 纯文本提取"]
    P2 -->|"scanned 扫描件"| X3["OCR 识别 → clean_ocr_text 清洗"]
    P2 -->|"two_column 双栏"| X4["two_column_handler 按栏序提取"]
    P2 -->|"image_rich 图文混排"| X5["multimodal_service 多模态提取"]
    P1 -->|"未知类型"| X2
    X1 --> P3
    X2 --> P3
    X3 --> P3
    X4 --> P3
    X5 --> P3

    P3{"文本非空？"} -->|"空"| PF(["success=false：未解析到文本"])
    P3 -->|"非空"| P4["mask_text 入库前脱敏<br/>计算 content_hash = MD5 前16位"]
    P4 --> P5["split_parent_child 父子切分<br/>build_parent_child_documents 构建块"]
    P5 --> P6["锁外批量计算子块 embedding<br/>（去重与入库复用，减少临界区耗时）"]
    P6 --> LOCK["进入 _dedup_commit_lock 临界区<br/>进程内 RLock（按 scope:owner:hash）<br/>+ Redis SET NX 跨副本锁（Lua CAS 释放）"]

    LOCK --> D0{"去重策略 _check_duplicate"}
    D0 -->|"full"| D1["全部子块向量扫全库<br/>find_max_similarity ≥ 阈值？"]
    D0 -->|"filename"| D2["SequenceMatcher 文件名相似 →<br/>content_hash 精确判重 →<br/>向量相似度判重"]
    D1 -->|"是"| SKIP
    D1 -->|"否"| NEW
    D2 -->|"hash 相同 / 相似"| SKIP["action=skip<br/>返回 skipped: 内容已存在"]
    D2 -->|"同名但指纹不同且不相似"| REP["action=replace"]
    D2 -->|"无同名文件"| NEW["action=new"]

    SKIP --> END
    NEW --> N1["add_parent_child 全量入库<br/>父向量 = 子块均值 L2 归一化"]
    N1 --> END
    REP --> U{"update_strategy"}
    U -->|"replace 策略A"| U1["replace_document<br/>先删旧块 → 写新块<br/>失败回滚"]
    U -->|"version 策略B"| U2["add_new_version<br/>旧版本打 superseded_at 标记<br/>新版本写入（保留历史）"]
    U1 --> END(["success：返回 doc_type / 父子块数 /<br/>action / version"])
    U2 --> END
```

## 4. 文档审核状态机

对应代码：`app/application/review/review_service.py`、
`app/infrastructure/persistence/repositories/document_review.py`。
三态 `pending / approved / rejected`，仅 pending 可审核；
`submit_for_review` 当前为 OCR/多模态提取后自动送审的预留入口，
尚无控制层调用点。

```mermaid
stateDiagram-v2
    direction TB
    [*] --> pending : submit_for_review()\nOCR/多模态提取完成后建记录\n（当前为预留入口，无控制层调用点）

    pending --> approved : approve()\n本人或 teacher/admin 代审
    pending --> rejected : reject()\n驳回原因 notes 必填
    approved --> [*]
    rejected --> [*]

    note right of pending
        前置校验（approve / reject 共用）：
        1. 记录存在
        2. 上传者账号未注销（软删 → 孤儿记录 404）
        3. status 必须为 pending，防重复审核
    end note

    note right of approved
        approve 附加步骤：
        1. edited_text 覆盖 cleaned_text（空文本拒绝）
        2. 重新 mask_text 脱敏
        3. update_status：id + 上传者 user_id 双键定位
        4. add_parent_child 写入【上传者】私有库
           （代审时不是审核者库）
        5. flush_persistent_index 立即落盘 HNSW 索引
        入库失败：状态已 approved，返回 success=false
    end note

    note right of rejected
        reject 仅更新状态，不触发向量入库
    end note
```
